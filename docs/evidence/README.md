# Evidence index

This directory stores dated proof artifacts for specific Navirox claims. Each
artifact should identify its input, command, result, limitations, and date.

Useful starting points:

- [Vue transform workspace run](vue-transform-workspace-run.md)
- [0.1.1 release candidate evidence](release-candidate-0.1.1.md)
- [Public distribution snapshot](release-candidate-2026-09-19.md)
- [Native pilot journey](native-pilot-journey.md)
- [Angular companion device evidence](angular-companion-device-evidence.md)
- [External validation](preview-external-validation.md)

An evidence file is not a general support claim. Machine paths should use
portable placeholders, and newer reproducible evidence supersedes an older
observation when the code has changed.
