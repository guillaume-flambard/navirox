# Vue/Nuxt developer preview contract

## Why

Navirox has meaningful deterministic analysis and bounded native evidence, but
is not ready to be represented as an automatic web-to-native converter. A
precise developer-preview contract is needed so the first public demonstration
creates trust without borrowing credibility from unproven visual fidelity,
public installation, or broad migration support.

## What Changes

- Add the canonical Vue/Nuxt developer-preview contract and evidence threshold.
- Record dependency-ordered follow-up changes without authorizing them.
- Link the contract from agent execution material while preserving the separate
  proof-journeys program.

## Capabilities

### New Capabilities

- `developer-preview-contract`: public-claim and reproducibility requirements
  for the Vue/Nuxt developer preview.

### Modified Capabilities

None.

## Impact

This is planning and public-claim documentation only. It changes no runtime,
adapter, target provider, transform, package or benchmark behaviour. It does not
repair CI, publish packages, contact external developers, or introduce an LLM.
