# Angular neutral seam proof

## Why

An Angular companion could be written manually and still pass a native device
journey. That would demonstrate native delivery, not Navirox's framework-neutral
source architecture. The Angular proof needs a minimum, observable use of the
source adapter and neutral model without promising a generic Angular UI compiler.

## What changes

- Define the minimum traceable Angular-to-neutral-model-to-companion path.
- Require provenance from an immutable Angular fixture or pinned benchmark
  finding through the adapter and planning output into the bounded companion.
- Add boundary checks that prevent Angular or provider imports leaking into
  neutral packages while the proof is implemented.

## Capabilities

### New Capabilities

- `angular-neutral-seam-proof`

### Modified Capabilities

- None.

## Impact

- Angular proof planning, adapter evidence, and architecture-boundary coverage.
- No generic Angular view compiler, real SuiteCRM integration, or public support
level change.
