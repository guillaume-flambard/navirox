## Why

Angular is the first enterprise-oriented source adapter, and SuiteCRM is the most
promising Angular commercial path found in the target research. The current adapter
has fixture coverage but no evidence that it can read a real SuiteCRM-shaped route
and component surface, nor a report that separates mobile companion candidates
from desktop-only CRM work.

This change makes Angular commercially useful without pretending it can generate a
native SuiteCRM application. It creates a repeatable readiness report and an
external benchmark diagnostic that guides a paid discovery with an integrator.

## What Changes

- Add a SuiteCRM-shaped Angular fixture covering standalone components, extension
  routes, services, template forms and browser-only capabilities.
- Extend the Angular source adapter only where this fixture exposes a proven
  reading gap. Unread or dynamic configuration remains a finding.
- Add a pinned, read-only SuiteCRM benchmark profile with a published route and
  component baseline.
- Add a mobile-companion classification to the Angular report that labels a route
  as candidate, desktop-only or unknown with evidence and never as automatically
  portable.
- Publish an evidence report and a SuiteCRM integrator discovery brief.

## Capabilities

### New Capabilities

- `angular-mobile-readiness`
- `suitecrm-benchmark`

### Modified Capabilities

- `source-angular`

## Impact

- `packages/source-angular`, its fixtures and tests, the benchmark catalog and
  scripts, the inspect or plan report type if a framework-neutral classification is
  justified, and evidence documentation.
- Out of scope: a SuiteCRM mobile app, an Angular target compiler, extraction of
  proprietary customer data, authentication against a real SuiteCRM instance,
  offline synchronization, EAS integration or any claim of official partnership.
